# Bank Management System

A C# console-based bank management system developed as a learning project to practice object-oriented programming, problem solving, and core software development concepts.

## Project Status

🚧 In Development

## Overview

This project is a simple console application that simulates basic banking operations.

The project is being developed progressively while practicing C# programming concepts and applying them in a practical project.

## Technologies

- C#
- .NET
- Console Application

## Learning Objectives

- Practice C# fundamentals
- Apply Object-Oriented Programming (OOP)
- Improve problem-solving skills
- Practice clean and readable code
- Learn basic project organization
- Practice Git and GitHub workflow
